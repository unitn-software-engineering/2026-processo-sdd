# AI-Native SDLC — Percorso didattico progressivo

Corso IS 2026 · Università di Trento

Ogni livello è un'iterazione completa: si può fermarsi in qualsiasi punto e consegnare un progetto funzionante. Il livello successivo non è un obbligo — è una scelta che risolve un problema concreto già vissuto.

Il progetto di riferimento è **EasyLib**, una piattaforma per la gestione dei prestiti bibliotecari universitari. Ogni livello introduce una User Story nuova e uno strumento nuovo, ma il progetto gira già dal Setup iniziale.
